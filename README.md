# Computer_Vision_Projects
Building computer vision projects that is interesting to try it out !

A growing collection of small computer vision projects, built to learn by doing. Each project lives in its own folder with its own README and setup instructions.

## Projects

| # | Project | Tech | What it does |
|---|---------|------|--------------|
| 01 | [Hand Tracking](01-hand-tracking) | Python, OpenCV, MediaPipe | Tracks hand landmarks in real time from a webcam |
| 02 | [YOLO Emotions](02-yolo-emotions) | Python, YOLO | Runs a YOLO model on webcam or image input |

## How to run a project

1. Clone the repo:
   ```bash
   git clone https://github.com/PearlM-457/Computer_Vision_Projects/wiki
   cd Computer_Vision_Projects
   ```
2. Open the project folder you want, for example `cd 01-hand-tracking`
3. Follow the setup steps in that folder's README
